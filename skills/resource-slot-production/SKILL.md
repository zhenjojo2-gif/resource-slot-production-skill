# Resource Slot Production

用于“需求文档 + 翻译文档/多国家表格 + Figma 完整范例国家 + Figma 现成组件”驱动的多国家资源位延展。用户提供的范例是版式、尺寸、层级、组件关系和视觉效果的唯一基准；不要重新设计范例，也不要先制作素材或首个国家。

## 使用前提

开始前确认 Figma 中已经具备：

- 一个完整国家范例，包含需求要求的全部资源位。
- 可直接复用的背景、国家标题、奖励框、箭头、按钮等组件素材。
- 可识别的范例国家 Section、各资源位 Component 和奖励容器 Instance。

如果缺少完整范例、目标国家标题组件或必要素材，列出缺项并暂停，不要自行补做素材或设计新的范例。

## 工作流程

### 1. 一次性整理数据

- 读取需求文档，确定待延展国家、各国本地活动时间、资源位清单和抽奖 Index。
- 读取翻译文档，建立紧凑的国家数据映射：国家代码、标题、说明文案、按钮文案和日期。文案必须来自表格，不得自行翻译；缺少翻译时记录缺项并暂停对应国家。
- 读取奖励资源表，按国家和 Index 整理奖励图；同一 Index 的奖励必须进入同一张抽奖 banner。
- 数据映射建立后本轮任务直接复用，不要为每个国家重复读取整份文档。

### 2. 一次性读取 Figma 范例

- 只读取一次范例国家的 Section 结构、资源位 Component、关键文本节点、标题实例、奖励实例和复用组件来源。
- 记录可替换字段与固定字段。固定字段包括画布尺寸、版式、背景、装饰、箭头、按钮背景和组件层级；可替换字段包括国家标题、翻译文案、活动时间、按钮文字和奖励图片。
- 默认直接复用范例的比例和位置。只有文字溢出、RTL 阅读顺序或奖励数量变化时才做必要适配。

### 3. 批量延展剩余国家

以国家为批次复制范例 Section，并完成：

1. 将国家代码和组件名称替换为目标国家。
2. 将标题替换为 Figma 中对应国家的标题 Component Instance。
3. 替换说明文案、本地活动时间和首页弹窗按钮文案。
4. 按 Index 覆盖奖励实例中的“奖励图片”，保持奖励背景框和实例关系不变。
5. 对长语言只调整文案区宽度、字号或行高；对 RTL 国家镜像阅读顺序和信息区。不要改变范例的视觉权重和整体构图。

不设置“素材确认”和“单国确认”节点；完成数据核对后直接延展需求中的全部剩余国家。

## 必须保持的组件规则

- 每个成品继续保持为独立 Figma Component，名称包含国家代码和资源位类型。
- 整个活动只保留 **1 个奖励容器母组件**，所有国家和资源位中的奖励容器均为该母组件的 Instance。
- 奖励实例只覆盖自己的“奖励图片”填充；不得 Detach Instance，不得为国家或单个奖励新增母组件。
- 奖励图必须为透明背景；白底缩略图可运行 `scripts/remove_connected_white.swift <input> <output.png>` 后再使用。
- 首页弹窗存在时，读取 [references/home-popup-buttons.md](references/home-popup-buttons.md)，按钮背景必须继续使用范例中的“按钮”组件实例，按钮高度 100–130px，文字 24px。
- 发生文字溢出、RTL、奖励数量变化或范例与需求不一致时，再读取 [references/final-product-rules.md](references/final-product-rules.md) 进行适配；普通复制任务不重复加载整份规则。

## 低 Token 的 Figma 执行方式

- 写入前遵循 `figma-use`；仅在确实要新增或修改母组件、变量或组件体系时使用 `figma-generate-library`。
- 范例结构只扫描一次；优先一次读取所需节点，不逐组件重复读取。
- 优先按国家批量写入。返回国家 Section 和顶层 Component ID 即可，不返回所有后代节点 ID。
- 状态文件按国家或整批更新一次，不在每个组件写入后重复记录。
- 默认每个国家只生成一张完整 Section 预览；如果多个国家可在一张图中清楚检查，也可使用一张合并预览。
- 只有结构校验或总览截图发现问题时，才单独读取、截图和修改某个组件。

## 批量校验

每个国家执行一次结构校验，整批完成后执行一次视觉校验：

- 资源位数量、类型和尺寸与需求及范例一致，开屏和首页弹窗不遗漏。
- 标题、说明、按钮和本地时间与国家数据映射一致。
- 抽奖 Index、奖励数量和奖励图片与资源表一致。
- 所有奖励容器指向同一个活动级母组件，实例图片互不串图。
- 箭头、按钮、奖励框、背景和装饰仍使用范例中的组件来源。
- 无文字、奖励或交互元素越界；底部安全区、描边和投影状态沿用范例。
- RTL 和长文本国家完成必要适配，但没有重新设计版式。

交付时提供目标国家清单、每个国家的 Section/顶层 Component ID、异常或缺项，以及最终预览和 Figma 链接。
